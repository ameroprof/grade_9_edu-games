# 🛡️ محارب الأمن السيبراني — Cyber Guardian
### لعبة تعليمية تفاعلية لمبحث المهارات الرقمية — الصف التاسع الأساسي
**درس: الجريمة الإلكترونية (الصفحات 32 إلى 41 حصرياً)**  
**تصميم وإعداد الأستاذ: عامر كراجه**

---

## 📌 فكرة اللعبة ومصدر المحتوى
لعبة ويب تعليمية تفاعلية مصممة بأسلوب الألعاب الحديثة (PUBG / Fortnite / Adventure Action) حيث يدخل الطالب عالمًا رقميًا افتراضيًا بصفته **"محارب الأمن السيبراني"** لحماية قطاعات مدينة رقمية من هجمات الجرائم الإلكترونية المختلفة.

### ⚠️ شروط المحتوى الصارمة:
- مستقاة حصرياً من **الصفحات 32 إلى 41** من كتاب المهارات الرقمية للصف التاسع (الفصل الأول).
- لا تحتوي أي معلومات من درس "التنمر الإلكتروني" (صفحة 42 وما بعدها).
- مشروع مستقل تماماً عن أي ألعاب أو وحدات أخرى.
- مصطلحات الكتاب الرسمية المعتمدة: الجريمة الإلكترونية، الاختراق (Hacking)، البرمجيات الخبيثة (Malware)، التلاعب بالبيانات (Data Manipulation)، التصيد والاحتيال (Phishing & Scam)، سرقة الهوية (Identity Theft)، هجمات الفدية (Ransomware Attack)، الابتزاز الإلكتروني (Cyberstalking)، قانون الجرائم الإلكترونية الأردني لعام 2023م (41 مادة، فارق 23 مادة)، ووسائل الوقاية السبع، والمواطنة الرقمية (5 ركائز).

## 🎮 محتويات ومراحل اللعبة (12 مهمة تكتيكية)
1. **المرحلة 1: رادار كشف الجريمة الإلكترونية** — فحص البصمات، مفهوم الجريمة، أوجه الشبه والاختلاف مع التقليدية (ص 33).
2. **المرحلة 2: شيفرة الانتشار والتشريعات** — أسباب انتشار الجريمة وتفكيك بنود قانون الجرائم الإلكترونية الأردني 2023 (ص 35–36).
3. **المرحلة 3: حصن السيرفر (صد الاختراق)** — لعبة تفاعلية لإغلاق المنافذ المفتوحة وحظر الوصول غير المصرح به (ص 34).
4. **المرحلة 4: مختبر عزل البرمجيات الخبيثة** — تصنيف وعزل الفيروسات وبرامج التجسس لحماية الأجهزة والبيانات (ص 34).
5. **المرحلة 5: خزانة البيانات (كشف التلاعب)** — تدقيق السجلات واكتشاف التغيير أو الحذف غير القانوني (ص 34).
6. **المرحلة 6: محاكي صندوق البريد (كشف التصيد)** — فحص واقعي للرسائل المضللة وعناوين النطاقات الاحتيالية (ص 34).
7. **المرحلة 7: حماية الهوية الرقمية** — سيناريو تكتيكي وترتيب خطوات التصدي لانتحال الشخصية للحصول على المال (ص 34).
8. **المرحلة 8: إنذار الفدية الرقمية (أنقذ الملفات)** — هجمة تشفير حاسمة: رفض دفع الفدية واستعادة النسخ الاحتياطي (Data Backup) (ص 34 & 37).
9. **المرحلة 9: وحدة مكافحة الابتزاز الإلكتروني** — التصرف الحاسم: رفض الخضوع، حفظ الأدلة، والإبلاغ الفوري (ص 34).
10. **المرحلة 10: بناء الدرع السيبراني 🛡️** — تجميع طبقات الوقاية السبع المذكورة في الكتاب لتوليد درع 100% (ص 37).
11. **المرحلة 11: منارة المواطنة الرقمية** — اختبار السلوكيات المسؤولة الخمسة بعد دراسة الجريمة (ص 38).
12. **المرحلة النهائية: معركة الزعيم السيبراني 🏆** — قتال تفاعلي ضد الروبوت الشرير (Zero-Day Bot) لإنقاذ المدينة وتحديد لقب الطالب النهائي (خبير / حارس متقدم / بحاجة لإعادة التدريب).

## 🚀 كيفية تشغيل اللعبة محلياً (Local Development)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- متصفح ويب حديث (Chrome, Edge, Firefox, Safari).

### 2. تثبيت التبعيات وتشغيل خادم التطوير
افتح موجه الأوامر (Terminal) داخل مجلد المشروع ونفّذ:

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير السريع
npm run dev
```

سيظهر رابط التشغيل المحلي:
`http://localhost:3000`

## 🛠️ كيفية التعديل والتخصيص

### 1. تعديل أو إضافة أسئلة وسيناريوهات
جميع الأسئلة مفصولة بشكل نظيف داخل الملف:
`/src/data/questions.ts`
- لتعديل سؤال أو خياراته أو شروحات التغذية الراجعة، عدّل مصفوفة `STAGE_QUESTIONS[stageId]`.
- لتعديل رسائل محاكي البريد، عدّل `INBOX_SIMULATION_EMAILS`.
- لتعديل ضربات الزعيم النهائي، عدّل `BOSS_ATTACKS`.

### 2. تعديل نصوص المرشد نوفا (Nova) وأسماء القطاعات
داخل الملف:
`/src/data/stages.ts`
- يمكنك تعديل الرسائل الترحيبية والتلميحات والعبارات التشجيعية الموجهة للطالب في كائن `novaText`.

### 3. تعديل العلامات والـ XP
- احتساب العلامة يتم بناءً على إنجاز المراحل والأسئلة ليكون المجموع النهائي من **100**.
- قيمة الـ XP الممنوحة لكل مرحلة محددة في خاصية `xpReward` داخل `/src/data/stages.ts`.
- يتم حفظ العلامات وسجل الطلاب تلقائياً في `localStorage` عبر مفتاح `cyber_guardian_records`.

### 4. إضافة مرحلة جديدة
1. أضف إعدادات المرحلة الجديدة في `/src/data/stages.ts`.
2. أضف أسئلتها وسيناريوهاتها في `/src/data/questions.ts`.
3. أنشئ مكوّن المرحلة في مجلد `/src/components/stages/`.
4. استدعِ المكوّن داخل `/src/App.tsx` عند مطابقة رقم المرحلة.

## 🌐 النشر على GitHub Pages أو خدمات الاستضافة

### النشر على GitHub Pages:
1. في ملف `vite.config.ts`، تأكد من ضبط خاصية الـ `base`:
   ```ts
   export default defineConfig({
     base: '/repository-name/', // استبدلها باسم المستودع لديك
     // ...
   })
   ```
2. ابنِ المشروع:
   ```bash
   npm run build
   ```
3. ارفع محتويات مجلد `dist/` إلى فرع `gh-pages` في مستودع GitHub الخاص بك، أو استخدم أداة `gh-pages`:
   ```bash
   npx gh-pages -d dist
   ```

### النشر على Vercel أو Netlify أو Firebase Hosting:
- اسحب المستودع مباشرة من GitHub، وسيقوم النظام بتشغيل أمر البناء `npm run build` تلقائياً وتحديد مجلد النشر `dist`.
